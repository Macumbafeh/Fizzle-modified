# Fizzle-modified
Modified version with CloseUp/AllStats-modified/Oglow addons included for WOTLK 3.3.5

- It display also Gems and Enchants text in character frame.
- Add a Background in the Character frame and Character Pet Frame.

- It display also Gems and Enchants text in character frame.
- Add a Background in the Character frame and Character Pet Frame.

## Features
This is Fizzle addon with some other addons integrated and some other features :

- Default Fizzle feature : Show item durability and quality in the character frame and inspect frame.
- CloseUp : You can zoom in/out and move your character with left/right click into the Character Frame and the DressingRoom Frame.
- oGlow : Make your shiny items glow with color depending on item quality. (Same than Fizzle but for everywhere else)
- AllStats Modified : Shows all of the stats from the dropdowns next to the paperdoll window.

I modified the skin of AllStats :
- Added Background 
- Texture in the title of each stats : All type of stats can be reduced (collapsed) if you left click on a title. or if you right click on it, it will remove the background only.
- Some type of stats are reduced by default depending on your Class (like a caster doesn't need Ranged/Melee stats...)

Other Features :
- Added a background like ElvUI on Character Frame and Character Pet Frame
- Removed Arrow to turn your Character since you can do it with your mouse now
- I moved the Resist Stats into AllStats
- Added Gems and Enchants text next to the items in the Character Frame, even empty gems are shown.
